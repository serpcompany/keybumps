Clipboard History keeps the text and images you copy, so you can use them again. Press ⇧⌘ Space to open the Clipboard tab of the Command Palette, search for an item, and press Return to copy it.

Each item shows the app it was copied from, and for a web page the site’s domain, whenever macOS can tell. Screenshots you take with Screenshot Tools land here too, ready to paste.

How to use it

  1. Copy text or an image the way you always do.⌘C
  2. Open the Clipboard tab from any app.⇧⌘Space
  3. Type to search, press Return to copy it again, then paste where you need it.↩⌘V

Key features

  • Keeps your 50 most recent copied text and image items
  • Search everything you copied, then press Return to copy it again
  • Shows the app each item came from, and the website’s domain when a browser says which page it was
  • Copying an image file in Finder keeps the image, not its icon
  • Text that Dictation inserts stays out, so the history holds only what you copied

Commands

Open its tab in the Command Palette, or use its shortcut from any app. You can change the shortcut in Settings › Clipboard History.

  • Clipboard tabCommand Palette⌘2
  • Open Clipboard History⇧⌘Space

Permissions and privacy

Clipboard History needs no macOS permissions.

What it keeps on your Mac

Your history stays on this Mac. Images up to 50 MB each are stored separately, so a full history can use several gigabytes.

Copied secrets remain until you delete them or newer copies replace them. For a website, only its domain is kept, never the full address.

New · FAQ + FAQPage

Questions

How much does it keep?

Your 50 most recent copied text and image items. Older items drop off as you copy new ones.

Does my clipboard history leave my Mac?

No. It stays on this Mac. For a web page, only the site’s domain is kept, never the full address.

What about passwords I copy?

Copied secrets stay until you delete them or newer copies replace them. Select an item and press Delete to remove it.

Can I paste screenshots from it?

Yes. Screenshots you take with Screenshot Tools land in Clipboard History, ready to paste.
