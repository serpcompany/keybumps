# Keybumps 0.0.3-beta.13

This beta is notarized by Apple again, so a fresh download opens without a warning. Nothing else changes from 0.0.3-beta.12.

> **Updating from 0.0.3-beta.11 or earlier?** Keybumps is now signed by a new Apple developer account, so macOS treats it as a new app:
> - **Permissions:** turn Keybumps back on in **System Settings › Privacy & Security** for each one you use: Accessibility, Input Monitoring, Screen Recording, Microphone, and Speech Recognition. **Keybumps Settings › Permissions** shows what's missing. If an old Keybumps entry is still listed, remove it with **−** and add Keybumps again.
> - **Keychain:** the first time Keybumps reads your license (and any sensitive snippets), macOS asks for your Mac login password. Type it and click **Always Allow**. If you clicked Deny, enter your license key again in Keybumps Settings.
>
> You also get everything from 0.0.3-beta.12: Snippets, with a Snippets tab (⌘5), keywords that expand as you type in any app, sensitive snippets, Import from Alfred, and snippets in Quick Search.

## Changes

- Notarized by Apple: downloads open normally, with no Open Anyway step.
