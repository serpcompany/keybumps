# Keybumps 0.0.3-beta.28

⇧⌘4 now opens the area you select in the Screenshot Editor, and Quick Search finds a snippet by a word in its text.

## ScreenGrabs

- ⇧⌘4 is now **Screenshot Area and Edit**: select an area, and it opens in the Screenshot Editor, as ⇧⌘3 does with your screens. **Save** (↩) copies it and saves an edited copy. Press Esc while you select, and nothing is taken. A shortcut you'd changed or cleared for it in Settings › ScreenGrabs stays as you set it.
- The Screenshot Editor's tools run Arrow, Text, Draw, Blur, Redact, and 1 to 5 pick them in that order. The editor opens with Arrow picked. The letter keys A, T, D, B and R still work.

## Quick Search

- Type part of a word in a snippet's text, and Quick Search finds it, as the Snippets tab does. Snippets that match by keyword or name are listed above ones that match only by text, and all of them come before files and folders.
- A snippet's row shows its text under its name. A sensitive snippet's text stays hidden and is never searched.
