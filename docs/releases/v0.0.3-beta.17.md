# Keybumps 0.0.3-beta.17

Keybumps can now tell us when it crashes, and you can tell us when something else goes wrong.

## Crash reports

- If Keybumps crashes or freezes, it sends a crash report to its developers through Sentry, so we can find and fix the cause. It's on by default.
- A report says where in Keybumps' code it happened, the Keybumps and macOS versions, your Mac's model and other technical details, which plugins are on, and a random identifier for your copy of Keybumps.
- Keybumps never adds your clipboard, snippets, transcripts, recordings, screenshots, searches, or window titles to a report, and it removes file paths, file names, links, and email addresses from error messages.
- Nothing is sent when nothing goes wrong.
- To stop sending them, turn off **Send crash reports** in Settings › General.

## Report a Problem

- Something not working, like a menu that won't open? Choose **Report a Problem…** from the Help menu, the menu of the Keybumps icon in the menu bar, or Settings › General.
- Describe what happened, and add your email if you'd like a reply. Before you send, the window shows the details Keybumps attaches, such as your macOS version and which plugins are on.
- Keybumps removes file paths, links, and email addresses from what you write, and sends the rest as you wrote it.
- It sends your report even when crash reports are off, because you chose to send it. If you're offline, Keybumps keeps it and sends it later.

The [privacy policy](https://keybumps.app/legal/privacy/) has the details.
