# Keybumps 0.0.3-beta.16

A plugin that's turned off now says so on its Settings page.

- When a plugin is off, its page in Settings shows a banner at the top saying it's turned off, with a **Turn On** button. Before, only the small switch at the top right showed it, which was easy to miss, such as when Quick Search opens the Emoji Picker's page because it ships off.
