# Keybumps 0.0.3-beta.3

This beta fixes first-run Quick Search setup when macOS Spotlight already owns Command-Space.

- Detects the exact enabled Spotlight shortcut conflict during onboarding.
- Releases only the matching Spotlight keyboard binding and immediately retries Keybumps Quick Search.
- Leaves custom and nonmatching shortcuts unchanged.
- Blocks onboarding with direct Keyboard Shortcuts recovery when automatic resolution cannot complete safely.
- Includes internal documentation and deterministic-test-fixture cleanup without changing local user content.
