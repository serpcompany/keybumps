# Keybumps 0.0.3-beta.25

Installing Keybumps takes one drag, and if you open it from anywhere else, Keybumps offers to move itself into Applications.

## Installing

- The download opens to a window with Keybumps and your Applications folder side by side. Drag Keybumps onto Applications to install it.
- If you open Keybumps straight from the download, it offers to move itself to Applications. Choose **Move to Applications** and it restarts from there and ejects the download. A ticked box also puts the downloaded file in the Trash.
- Opened from your Downloads folder, it makes the same offer, and the copy in Downloads goes to the Trash once Keybumps is in Applications.
- If Applications already has this version of Keybumps or a newer one, it offers to open that copy instead.
- Running from Applications is what lets Keybumps install updates and keep the permissions you give it.
