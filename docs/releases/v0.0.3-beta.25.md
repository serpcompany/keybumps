# Keybumps 0.0.3-beta.25

Installing Keybumps takes one drag, and Keybumps moves itself into Applications if you open it from anywhere else.

## Installing

- The download opens to a window with Keybumps and your Applications folder side by side. Drag Keybumps onto Applications to install it.
- If you open Keybumps straight from the download or from your Downloads folder, it offers to move itself to Applications. It restarts from there, ejects the download, and can put the downloaded file in the Trash.
- If Applications already has this version of Keybumps or a newer one, it opens that copy instead.
- Running from Applications is what lets Keybumps install updates and keep the permissions you give it.
