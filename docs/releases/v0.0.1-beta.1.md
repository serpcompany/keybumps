# SuperMac v0.0.1-beta.1

First private beta of SuperMac, a local macOS companion combining:

- Quick Search for applications, files, and folders
- bounded text-and-image Clipboard History
- local Dictation with multi-span transcript assembly, per-recording transcript/audio history, interrupted-recording recovery, and manual retranscription
- shared waveform playback for original and temporary translated audio, with a compact native speed picker
- Rectangle-style Window Management shortcuts and drag-to-snap
- Key Bumps shortcut coaching
- guided macOS permission setup

## Install

1. Download `SuperMac-v0.0.1-beta.1.dmg`.
2. Open the disk image.
3. Drag SuperMac into Applications.
4. Launch SuperMac and complete its guided permission setup.

This build targets Apple silicon and macOS 14.2 or newer.

## Beta limitations

- Production licensing and automatic updates are not configured.
- The app is distributed from this private repository for beta testing.
- Microphone, Speech Recognition, Accessibility, and Input Monitoring behavior still depends on the permissions granted by the tester.
- Some owner-acceptance journeys remain open, including complete physical verification of every window action, live image Clipboard History, audible translated speech/speed changes, force-quit recording recovery, login-session relaunch, and clean-machine installation.
