# Keybumps 0.0.3-beta.19

The Command Palette gets a compact tab bar and works more like Raycast. There's also a new Translation plugin.

## A quicker Command Palette

- Tabs are now icons, so every tab fits, and the open tab shows its name. Hold ⌘ to see each tab's number, then press it to switch.
- With the search field empty, ← and → switch to the tab beside the one you're on.
- Type **/** to filter a tab's items. Clipboard filters by Text, Images, or Links. Screenshots and Dictation filter by Today or This Week, and Dictation also by Failed or Interrupted. Search filters by Apps, Files, Folders, Commands, or Snippets.
- Moving the pointer over a row highlights it, as in Raycast, and the highlighted row stays on screen as you move through a list.
- Deleting a Dictation recording from the palette now asks first.
- The palette's ⌘ keys work while Caps Lock is on.

## New: Translation

Translation is a new plugin for macOS 15 or later. It's off until you turn it on in Settings › Plugins.

- Its Translate tab (⌘8) translates what you type or paste as you go, with macOS's built-in translation.
- Text in your language goes to your other language, and text in any other language comes back to yours. Choose both languages in Settings › Translation.
- Press ⌘T to translate the other way, or click the target language to pick another.
- Return copies the translation, without adding it to Clipboard History. ⌘Return pastes it into the app you were using.
- If a language isn't downloaded yet, the tab says so, with a button that opens Language & Region in System Settings, where you can download it.

## Also new

- With Emoji Picker on, Quick Search finds emoji too. To turn that off, use **Show emoji in Quick Search** in Settings › Emoji Picker.
- When you set a shortcut that another Keybumps action already uses, Keybumps tells you which one and asks before moving it.

## Fixed

- Dictation's Translate offers English for text in another language, and choosing a language that needs a download no longer closes the palette.
- Pressing Esc while Dictation's model is loading stops the wait, and the next dictation works.
- A Dictation recording cut off by a crash can be retried.
- Copying a Clipboard History image whose file is missing no longer empties your clipboard.
- On a small screen, the Settings window fits above the Dock.
- The Command Palette's rounded corners no longer show a square edge.
