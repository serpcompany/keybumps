# Keybumps 0.0.3-beta.21

Copy, paste, and play from the Command Palette with ⌘C, ⌘P, and Space.

## New keys in the Command Palette

- On a highlighted row, ⌘C copies it and ⌘P pastes it into the app you were using. This works in Clipboard, Screenshots, Snippets, Emoji, Dictation, and Translate, and for snippets and emoji in Search.
- ⌘Return no longer pastes. It now does what Return does, except in Screenshots, where it still opens the editor, and in Search, where it still shows an app or file in Finder.
- With the search field empty, Space plays or pauses a Dictation recording, and reads a saved translation aloud or stops it.
- With text selected in the search field, a transcript, or a translation, ⌘C copies just that text.
- The footer shows each action's key.

## Fixed

- When a shortcut you record in Settings is already used by another action, VoiceOver now reads out the question.
- Only one shortcut field records at a time, and your Keybumps shortcuts stay paused until it finishes.
- In a narrow Settings window, Window Manager's shortcuts keep their two columns.
