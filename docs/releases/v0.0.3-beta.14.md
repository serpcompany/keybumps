# Keybumps 0.0.3-beta.14

Updates are now hard to miss, so you always have the newest features.

## Updates

- Keybumps checks for updates every hour.
- When an update is ready, Keybumps asks you to restart. **Restart Now** takes a few seconds; **Later** asks again in an hour.
- It never asks while you're dictating, editing a screenshot, or using the Command Palette, and it never restarts on its own.
- While an update is waiting, the menu bar icon shows a red dot, and **Restart to Update** is the first item in its menu.
- After each update, this window shows what's new.
