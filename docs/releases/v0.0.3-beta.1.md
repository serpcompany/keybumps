# Keybumps 0.0.3-beta.1

Production-signing baseline for the clean Keybumps identity and update origin.

- Uses the `com.serp.keybumps` bundle identity.
- Trusts the new Keybumps production Sparkle key.
- Checks the controlled staging feed for the first N to N+1 update proof.

This baseline is installed manually for release verification and is not the promoted customer download.
