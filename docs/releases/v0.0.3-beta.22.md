# Keybumps 0.0.3-beta.22

Read a whole saved translation, and switch Command Palette tabs without the layout jumping.

## Translate

- Saved translations now open like Dictation's recordings: the list on the left, and the highlighted translation in full on the right, with its source text, its languages, and when you saved it.
- Long translations scroll in full instead of being cut off.
- Copy, Paste, Read Aloud, and Delete are buttons on the right, each showing its key.

## Command Palette

- Every tab's rows now line up the same way, so switching tabs with ← and → no longer shifts the icons, text, or grid edges.

## Settings

- Clipboard History, Screenshot Tools, and Snippets show the optional Accessibility permission that ⌘P uses to paste, with a button to allow it.
