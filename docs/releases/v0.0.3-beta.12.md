# Keybumps 0.0.3-beta.12

This beta adds Snippets: save text you reuse, find it from the Command Palette or Quick Search, and have keywords expand as you type in any app.

> **This beta is not notarized yet.** It's signed with our new Developer ID, and Apple is still setting up notarization for it. If you download it fresh, macOS blocks the first launch: open **System Settings › Privacy & Security** and click **Open Anyway** next to the Keybumps message. Updating from inside Keybumps works normally.

> **After this update, macOS treats Keybumps as a new app.** Keybumps is now signed by a new Apple developer account, so macOS asks again for what it allowed before:
> - **Permissions:** turn Keybumps back on in **System Settings › Privacy & Security** for each one you use: Accessibility, Input Monitoring, Screen Recording, Microphone, and Speech Recognition. **Keybumps Settings › Permissions** shows what's missing. If an old Keybumps entry is still listed, remove it with **−** and add Keybumps again.
> - **Keychain:** the first time Keybumps reads your license (and any sensitive snippets), macOS asks for your Mac login password. Type it and click **Always Allow**. If you clicked Deny, enter your license key again in Keybumps Settings.

## Snippets (new)

- Save text you reuse in **Settings › Snippets**, each with a name and an optional keyword such as `;ship`.
- Open the **Snippets tab (⌘5)** in the Command Palette: Return copies a snippet and ⌘Return pastes it into the app you're using.
- **Expand keywords as you type:** turn it on in Settings › Snippets, then type a keyword in any app and Keybumps replaces it with the snippet and puts your clipboard back. It never expands in password fields or in Keybumps itself, and it needs Input Monitoring and Accessibility.
- **Sensitive snippets** keep their text in the Keychain and hide it in the palette and Settings.
- **Import from Alfred:** bring in an Alfred snippets export from Settings › Snippets.
- The Snippets table sorts by column, and you can select several snippets to delete them or mark them Sensitive together.

## Quick Search

- Quick Search (⌘1) finds snippets by keyword and name. A keyword typed in full comes first.
- Find any Keybumps feature by typing its name, such as "dictation" or "snippets".

## Fixes

- Screenshots tab: Return copies a screenshot and ⌘Return opens it in the editor.
- Clearing the Clipboard tab no longer clears the Screenshots tab.
- Dictation asks for the Accessibility access it needs to paste.
- Shortcut Coach no longer makes Keybumps freeze after clicks.
- The palette's buttons no longer show a thin line at their ends.
