# Architecture

`SuperMacApp` and `AppModel` own composition and lifecycle. Feature services own behavior but never create another app delegate, status item, Settings scene, updater, license system, or launch-at-login controller.

The shared `GlobalShortcutCoordinator` is the sole Carbon hot-key registrar. `AppPreferences` persists the editable Quick Search, Clipboard History, Dictation, and Window Management bindings; assigning one key combination removes it from any previous owner before the coordinator re-registers the complete valid set. Dictation temporarily registers unmodified Escape only while Recording or Transcribing can still be cancelled before insertion. `PermissionCoordinator` centralizes truthful permission state and recovery. Each capability stops its service and releases its shortcut when disabled. `ClipboardHistoryService` excludes only the exact pasteboard change written by automatic Dictation delivery, so a subsequent user copy—even of identical text—is still captured.

`NativeStatusItemController` retains the SwiftUI main-window opener configured while the initial window is alive. The status menu, Dock reopen path, and Key Bumps menu panel call that persistent route directly, so closing the Settings window does not remove the only listener capable of recreating it. The app uses one SwiftUI `Window` scene and disables automatic macOS window tabbing, so every route reuses the same Settings window.

`CommandPaletteController` owns one floating keyboard-first surface for Quick Search, Clipboard History, Dictation History, and Key Bumps History. Command-1/2/3/4 select those tabs in order; tab chrome uses only the shortcut and name. The palette tracks its native Clear History confirmation as an internal presentation, so sheet focus changes and alert-button clicks do not trigger outside-click dismissal. Clipboard metadata retains bounded JSON persistence; image payloads live as separate files under Application Support so the index stays small and deletion/eviction can remove media independently. `DictationHistoryService` owns the independently stored `~/Documents/SuperMac/recordings/<timestamp>/meta.json` and `output.wav` pairs. It persists recording/transcribing/completed/interrupted/failed lifecycle state, suppresses recovery of sessions known to be live in the current process, and converts stale pending or legacy playable audio-only folders into retryable interrupted entries after relaunch. The dedicated History screen and Command Palette share the same card controls for retry transcription and adjustable local playback.

`DictationAudioTransportView` is the single visual playback component for original and translated speech. `TranslatedSpeechPlayer` selects an installed locale-matched voice, renders speech into a temporary local WAV, and composes the shared `DictationAudioPlayer`; closing or changing the translation stops playback and deletes the temporary file. Translated audio never enters the durable per-recording archive.

Key Bumps retains its donor separation between Detection, Delivery, Infrastructure, Domain, and Views. Every preview executes the same production channel adapter as real delivery without writing a history event. Custom presentations share one close, Escape, horizontal-swipe, and hover-paused dismissal lifecycle; position changes only placement. Sound is configured separately from visual presentation channels, and unsupported legacy Cursor Halo selections are removed while loading preferences. Window frame calculations and the Rectangle-inspired settings grouping/preview model remain pure and separately testable from Accessibility execution. Dictation owns no guide or assistant behavior.
